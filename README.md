# NEMORA website

Static site for nemora.uk, hosted on GitHub Pages (custom domain in `CNAME`).

- Pages: `index.html`, `services.html`, `work.html`, `about.html`, `contact.html`, `privacy.html`, `404.html`
- Styles and scripts: `assets/site.css`, `assets/site.js` (no frameworks, no third-party requests)
- Fonts are self-hosted in `assets/fonts` (Inter and a renamed Lora subset, both SIL Open Font License)
- The contact form opens the visitor's email app addressed to daniel@nemora.uk (no form service needed)
- Portfolio screenshots are in `assets/work`
